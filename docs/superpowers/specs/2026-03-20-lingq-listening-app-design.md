# LingQ 风格英语听力学习 App — 设计规格文档

## 概述

一款 iOS 英语听力理解与词汇积累 App。用户导入 MP3 音频文件和 SRT 字幕文件，通过两种互补模式进行学习：精读模式（逐词交互）和泛听模式（歌词式沉浸）。核心是 LingQ 风格的四级词汇系统，配合间隔重复实现长期记忆。

## 目标平台

- **设备：** 仅 iPhone
- **最低 iOS 版本：** 18.0
- **UI 框架：** SwiftUI
- **架构：** 模块化 Swift Packages（各模块内部使用 MVVM）
- **持久化：** SwiftData
- **音频：** AVFoundation
- **词典：** iOS 系统内置词典
- **后端：** 无 — 完全离线、仅本地存储

## 模块架构

```
lingQ/
├── App/                          # 主 Xcode 工程（SwiftUI App target）
├── Packages/
│   ├── SharedModels/             # 跨模块类型：Course、SubtitleCue、WordLevel
│   ├── SubtitleKit/              # SRT 解析、按时间戳查找字幕
│   ├── AudioPlayerKit/           # AVFoundation 封装、播放控制
│   ├── VocabularyKit/            # 生词增删改查、级别管理、SwiftData 模型
│   └── SRSKit/                   # SM-2 间隔重复算法（纯逻辑）
```

### 依赖关系图

```
App → SubtitleKit, AudioPlayerKit, VocabularyKit, SRSKit, SharedModels
VocabularyKit → SRSKit, SharedModels
AudioPlayerKit → SharedModels
SubtitleKit → SharedModels
SRSKit → （无依赖）
SharedModels → （无依赖）
```

### 各模块职责

**SharedModels** — 跨模块共享的值类型和协议。无 UI、无持久化。

**SubtitleKit** — 将 SRT 文件解析为 `[SubtitleCue]`。提供二分查找，根据给定时间戳定位当前字幕。纯 Swift，可独立单元测试。

**AudioPlayerKit** — 封装 AVFoundation，对外暴露一个 `@Observable` 播放器：
- 播放 / 暂停 / 跳转
- 播放速率（0.5x–2.0x）
- 发布当前播放时间用于字幕同步
- AB 循环范围用于单句复读
- 后台音频会话配置

**VocabularyKit** — 基于 SwiftData 的生词存储，负责：
- 创建和更新生词及其级别（1/2/3/已掌握）
- 按课程、按级别或全局查询生词
- 通过 SRSKit 调度复习
- 存储上下文句子（生词出现的原句）

**SRSKit** — 纯函数模块，实现 SM-2 算法。输入：当前难度系数、重复次数、用户评分。输出：下次复习日期和更新后的参数。无持久化、无依赖。

## 数据模型

### Course（课程）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| title | String | 显示名称（取自文件名或用户编辑） |
| audioFileURL | URL | 导入音频文件的 Bookmark URL |
| subtitleFileURL | URL | 导入 SRT 文件的 Bookmark URL |
| createdAt | Date | 导入时间 |
| lastPlayedAt | Date? | 最后打开时间 |
| playbackPosition | TimeInterval | 上次播放位置（断点续播） |
| folder | String? | 可选的文件夹/分组名称 |

### SubtitleCue（字幕条目）

| 字段 | 类型 | 说明 |
|------|------|------|
| index | Int | SRT 中的序号 |
| startTime | TimeInterval | 开始时间（秒） |
| endTime | TimeInterval | 结束时间（秒） |
| text | String | 字幕文本内容 |

### Word（生词）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| text | String | 原词 |
| lemma | String? | 词根/原形 |
| level | WordLevel | 当前掌握级别 |
| definition | String? | 缓存的词典释义 |
| phonetic | String? | IPA 音标 |
| contextSentence | String? | 来源字幕句子 |
| courseId | UUID? | 所属课程 |
| createdAt | Date | 首次标记时间 |
| nextReviewAt | Date? | SRS 下次复习日期 |
| reviewCount | Int | 已复习次数 |
| easeFactor | Double | SM-2 难度系数（默认 2.5） |

### WordLevel（生词级别）

| 值 | 整数 | 颜色 | 含义 |
|----|------|------|------|
| new | 0 | 浅蓝色 | 未标记，首次遇到（显示为普通文本，无特殊装饰） |
| level1 | 1 | 绿色 | 刚认识 |
| level2 | 2 | 紫色 | 学习中 |
| level3 | 3 | 蓝色 | 接近掌握 |
| known | 4 | 灰色 ✓ | 完全掌握 |

## 页面与 UI 设计

所有页面支持浅色和深色主题，默认跟随 iOS 系统外观，App 内可手动覆盖。视觉设计遵循 Figma 文件：`figma.com/design/f3zPdc6jNwaTW6YlhyVRo5/LingQ`

### 设计语言（从 Figma 提取）

**深色主题：**
- 背景：深海军蓝/炭灰色（`#0D1117` 范围）
- 卡片/表面：`#1C2333`，带细微边框
- 强调色：蓝色 `#4A90D9`
- 文字：白/浅灰层级
- 装饰：背景中的渐变模糊光效

**浅色主题：**
- 背景：米白色 `#F8F9FB`
- 卡片/表面：白色，带轻阴影
- 强调色：紫色 `#6C5CE7`
- 文字：深灰/黑色层级

**通用设计模式：**
- 圆角胶囊徽章用于统计（NEW / LEARNING / KNOWN）
- 玻璃拟态浮动播放器面板
- 系统 SF 字体；标题使用斜体
- 四级生词状态：圆形编号按钮（1 / 2 / 3 / ✓）

### 页面 1：课程列表

App 首页，管理导入的音频+字幕对。

**布局：**
- 导航标题 + 右上角"+"导入按钮
- 可滚动的课程卡片列表
- 每张卡片：标题、时长、进度条、词汇统计徽章
- 支持文件夹分组（可折叠区域）
- 滑动删除；长按显示选项（重命名、移动到文件夹）
- 空状态：导入提示，显示支持的格式信息

**导入流程：**
- 点击"+"打开 iOS 文档选择器（UTType: .audio 用于 MP3，.plainText 用于 SRT）
- 按文件名自动配对（如 `lesson1.mp3` + `lesson1.srt`）
- 若无法自动匹配，提示用户手动选择对应文件
- 通过 Security-Scoped Bookmark 存储文件引用

### 页面 2：精读模式

全文阅读视图，支持逐词交互。基于 Figma 中 "Intensive Mode - Grey Black"（深色）和 "image 1"（浅色）。

**顶部导航：**
- 返回箭头 + 课程标题（斜体）+ 菜单/头像按钮

**统计栏：**
- 胶囊徽章：X NEW（绿）/ X LEARNING（紫）/ X KNOWN（深色/灰色）
- 用户标记生词时实时更新

**阅读画布：**
- 全文垂直滚动
- 每个单词独立渲染以支持点击交互
- 未知/学习中的词：对应级别颜色的下划线标记
- 已掌握的词：无装饰（正常文字）
- 当前播放句子：背景高亮（深色模式蓝色、浅色模式紫色）
- 自动滚动保持当前句子可见

**查词弹窗：**
- 点击文本中的任意单词触发
- 卡片覆盖层显示：
  - 单词（大号加粗）
  - 音标（如 `/ˌiːkwɪˈlɪbriəm/`）
  - 级别徽章："LEVEL 2 · INTERMEDIATE"
  - 释义区域，含词性
  - 四个圆形级别按钮：`1` `2` `3` `✓`
  - 发音按钮（系统 TTS）
  - 关闭按钮（×）
- 释义来源：iOS 系统内置词典，使用 `UIReferenceLibraryViewController`（公开 API，支持离线查询）

**底部浮动播放器（胶囊）：**
- 紧凑胶囊锚定在底部，带模糊背景
- 上一句 / 播放暂停 / 下一句 按钮
- 进度条 + 当前时间 / 总时长
- 点击可展开（显示速度控制等）

**可用的播放控制：**
- 播放 / 暂停
- 跳转到上一句 / 下一句（基于 SRT 字幕条目）
- 播放速度：0.5x、0.75x、1.0x、1.25x、1.5x、2.0x
- 单句循环（点击循环图标重复当前字幕）

### 页面 3：泛听模式

全屏歌词式视图，沉浸式听力体验。基于 Figma 中 "Immersive Mode - Grey Black"（深色）和 "Body"（浅色）。

**顶部栏：**
- 关闭按钮（×）— 返回课程列表或精读模式
- 进度指示条（细水平线显示播放位置）
- "FLOW STATE" 胶囊标签，带音频波形图标
- 设置齿轮按钮（播放速度、定时器）

**歌词画布（居中）：**
- 文字垂直居中排列，每行一句
- 当前句子：大号、加粗，深色模式白色带发光效果，浅色模式深色
- 之前的句子：在上方渐隐，逐渐变得更透明
- 之后的句子：在下方渐隐，逐渐变得更透明
- 句子切换时平滑滚动动画
- 点击任意句子跳转到对应播放位置

**当前句状态：**
- 当前句子下方：胶囊徽章显示词汇状态（如 "LEARNING"），仅当句子包含学习中的词时显示

**子模式（底部标签）：**

**Focused（专注）：**
- 每句播完后短暂自动暂停（0.5–1 秒，可配置）
- 当前句子显示词级别状态指示
- 点击当前句子单句重播
- 点击当前句中的单词可快速标记级别（迷你弹窗）

**Ambient（环境）：**
- 连续播放，不暂停
- 简化视觉：不显示词汇状态指示
- 更慢、更平滑的滚动动画
- 最少交互 — 设计用于被动听力

**底部播放器面板：**
- 玻璃拟态卡片，带模糊背景
- 进度条 + 时间戳（02:45 / 04:20）
- 控制键：回退 10 秒 / 上一句 / 播放暂停（大号居中）/ 下一句 / 快进 10 秒
- 模式标签在下方：`FOCUSED` · `AMBIENT`（活动状态用圆点指示）

**模式切换：**
- 在精读和泛听模式之间可水平滑动切换
- 或使用导航区域的专用切换按钮

浏览和管理所有已保存的生词。

**布局：**
- 顶部标签页："全部生词" / "按课程"
- 搜索栏用于筛选
- 级别筛选胶囊：1 / 2 / 3 / 已掌握 / 全部
- 单词卡片列表：
  - 单词 + 音标
  - 简短释义（单行，截断显示）
  - 级别指示（彩色圆点或编号圆圈）
  - 课程来源标签（小号灰色）
- 点击单词卡片展开或显示查词弹窗（复用精读模式中的组件）
- 滑动删除或修改级别

- 按字母顺序
- 按级别
- 按下次复习日期

### 页面 5：闪卡复习

使用 SM-2 算法的间隔重复复习。

**入口：**
- 课程列表或标签栏上显示 "X 个单词待复习" 徽章

**复习流程：**
1. 显示卡片数量："12 个单词待复习"
2. 卡片正面：单词（大号居中）+ 音标
3. 用户点击 "显示答案" 或上滑
4. 卡片背面：释义 + 上下文句子（来自原始字幕）+ 音频播放按钮
5. 底部评分按钮：`重来` / `困难` / `良好` / `简单`
6. 卡片动画移走，下一张出现
7. 全部完成后：显示统计摘要页

**统计摘要页：**
- 总复习数量
- 分类统计：X 重来 / X 困难 / X 良好 / X 简单
- "继续" 或 "完成" 按钮
- 下次复习时间预估

**算法（SM-2）：**
- `重来`：重置重复计数，1 分钟后复习
- `困难`：间隔 × 1.2，难度系数 -= 0.15（最低 1.3）
- `良好`：间隔 × 难度系数
- `简单`：间隔 × 难度系数 × 1.3，难度系数 += 0.15

## 文件导入流程

1. 用户在课程列表点击"+"
2. 打开文档选择器（启用多选）
3. App 接收文件 URL，创建 Security-Scoped Bookmark
4. 自动配对逻辑：匹配 `filename.mp3` 与 `filename.srt`
5. 若无法配对，提示用户手动选择匹配文件
6. 在 SwiftData 中创建新的 `Course` 记录
7. 立即解析 SRT；存储字幕条目数量用于统计
8. 用户导航至新课程

支持的格式：
- 音频：`.mp3`、`.m4a`、`.wav`、`.aac`
- 字幕：`.srt`（MVP），后续可扩展 `.vtt`/`.lrc`

## 主题系统

- 默认：跟随 iOS 系统的 `colorScheme` 设置
- App 内覆盖：浅色 / 深色 / 跟随系统（存储在 `@AppStorage`）
- 颜色在 Asset Catalog 中定义，包含浅色/深色变体
- 生词级别颜色针对每个主题调整对比度
- 语义色彩 Token：`background`、`surface`、`textPrimary`、`textSecondary`、`accent`、`level1`、`level2`、`level3`、`known`

## 关键技术决策

1. **SwiftData 优于 Core Data** — iOS 18+ 可使用 SwiftData 最新特性。更简洁的 API，原生 Swift 集成，`@Query` 宏实现响应式 UI。

2. **Security-Scoped Bookmark 用于导入文件** — 从文档选择器导入的文件需要持久化访问权限。Bookmark 可在 App 重启后存活。

3. **Observable 宏用于播放器状态** — `AudioPlayerKit` 暴露 `@Observable` 类，SwiftUI 视图可响应式更新播放时间、播放状态等。

4. **SRT 解析器作为纯函数** — `SubtitleKit.parse(fileURL:) -> [SubtitleCue]` 无状态，易于单元测试。使用二分查找在字幕条目中以 O(log n) 复杂度按时间戳查找。

5. **SM-2 作为纯函数模块** — `SRSKit` 零依赖。输入参数，输出调度结果。可无需 mock 进行详尽的单元测试。

6. **单词分词** — 使用 `NLTokenizer`（NaturalLanguage 框架）将字幕文本拆分为可点击的单词，实现准确的英文单词边界检测。
